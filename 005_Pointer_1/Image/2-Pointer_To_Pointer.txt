        ┌──────────┐        ┌──────────┐        ┌──────────┐
        │    pp    │        │    p     │        │    x     │
        │ 0x2000   │        │ 0x1000   │        │ 0x0000   │
        ├──────────┤        ├──────────┤        ├──────────┤
        │ 0x1000   │───────►│ 0x0000   │───────►│   42     │
        └──────────┘        └──────────┘        └──────────┘

        int** pp = &p;      int* p = &x;        int x = 42;

        **pp  = value of x = 42
        *pp   = value of p = 0x0000 (address of x)
        pp    = address of p = 0x1000
